Centre de relances

Préparées — envoi manuel

Les relances arrivées à échéance apparaissent ici. Tu peux préparer un message et l'ouvrir dans ton application e-mail. N'envoie un message qu'aux contacts pour lesquels tu as une base légale et les autorisations nécessaires.

Paramètres de démonstration

Les données restent enregistrées dans le stockage local du navigateur sur cet appareil. Elles ne sont ni synchronisées ni sauvegardées sur un serveur.

À connecter pour une vraie mise en production

  • Authentification et base de données hébergée.
  • Envoi d'e-mails via un fournisseur transactionnel.
  • Planificateur serveur pour les relances.
  • Paiements récurrents et gestion des abonnements.
  • Consentement, désinscription, journal d'envoi et conformité RGPD.
